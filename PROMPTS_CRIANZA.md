## NOTAS GENERALES PARA TODAS LAS IMÁGENES:

1. **Estilo consistente:** Ilustraciones digitales modernas, profesionales y minimalistas
2. **Sin rostros detallados:** Usar siluetas o rostros simplificados para universalidad
3. **Calidad:** Alta resolución, formato JPG optimizado para web
4. **Tono general:** Cálido, profesional, accesible y esperanzador
5. **Evitar:** Violencia explícita, imágenes perturbadoras, contenido sensible
6. **Incluir:** Elementos simbólicos, metáforas visuales, colores emocionales
